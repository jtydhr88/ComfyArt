# #643 Wash SOP（示例图洗图规范）

本规范适用于 skill 的 cover / examples / featured 示例图洗图。按**槽位类型**分两套规则，先判断槽位属于哪一类，再按对应规则做；第 C、D 节两类通用。

---

## A. 人物 / 照片类槽位（person / photo）

适用：画面主体是真人照片的槽位，例如 pose-fission、ai-model、portrait 类。

### 1. Pilot 先行
- 每个新槽位**先做 1 张 pilot**，拿到**设计 PASS**，再拿到 **Angela 的 OK**，之后才做全套（#670 ex01 就是这样走的）。

### 2. 方法：以金标为底图的局部重绘
1. **底图 = 金标**。用 kie（`gpt-image-2-5-flare-image-to-image`）对金标做编辑：只换脸，外加 1–2 处小场景细节。
2. 用**羽化遮罩**合成（Pillow/numpy），只贴回：
   - **脸/头发**：椭圆遮罩做高斯羽化，再乘一条在**领口线处降到 0** 的竖向渐变（约 40px）。衣服像素一个也不进遮罩。
   - **1–2 个小场景框**：羽化只做在框内，框不能碰衣服。
3. 遮罩以外的像素**全部是金标原像素**：衣服、姿势、光线、调色、颗粒都不动。在 PNG 母版上验收：遮罩为 0 的像素与金标**逐字节相同**。
4. **重绘后放大 2 倍检查**：沿遮罩边缘逐段看有没有接缝、晕边、色阶断层，并确认金标原文字**没有残留**（包括半透明残影）。
5. **禁止**：全图重生成、重滤镜（整体调色/风格化 LUT）、磨皮。只允许局部重绘。

### 3. 换脸标准（Angela 原话要求）
- **照片级真实**：皮肤、头发、光线质感真实，**没有 AI 感**。
- **商业模特级颜值**：只能更好看，**绝不能更丑、更老**。
- **妆容和造型精致度不低于金标**。"真实"不等于丑。
- **角度跟随每张金标**：侧脸、四分之三侧、回头都要照着来，不能全部改成正脸。视线和受光方向也跟金标一致；发丝边缘干净，没有羽化晕边。
- 必须是**另一个人**，半屏一眼能分辨。

### 4. 人物一致性
- **连续性槽位**（如 pose-fission）：所有示例**只用一张新脸**。从第一张成品取人物参考（multi-ref Image 2）。
- **ai-model 类槽位**：每个示例换**不同的人**，各自匹配对应金标的**族裔、风格和妆容**；同一槽位的示例之间**不能出现重复的脸**。

### 5. 光线、调色、颗粒保持金标
- 光线、调色、颗粒一律保持金标。**#670 的一版就是因为这一点被 Angela 拒的**（重打光改动太大）。
- **脸部亮度**（遮罩 > 0.5 区域的平均亮度）与金标之差必须在 **±3** 以内（硬性门槛）。做法：合成前给编辑图乘增益 `gain = mean(L_gold) / mean(L_edit)`。
- **暗部颗粒**要和金标一致。指标是脸部暗部（遮罩 > 0.5 且 L < 70）的 high-pass（σ=2）std，成品对金标。编辑图颗粒偏粗时降低其高频；偏细时在遮罩内补单色噪声。

### 6. 场景细节与文字
- 场景轻改（换 1–2 处小物体）如果让画面更好，可以接受，但不能漂移主题。
- **整块替换**场景物体，不要叠加在原物体上。例如把整块排水篦子（连框带花纹）换成铺地砖，而不是在篦子里叠一个圆井盖。
- 金标里的文字要清掉（规则同 B.2）。

### 7. 遮罩的坑（#670 经验）
- **不要用硬边的排除矩形**。#670 ex04 的袖口排除矩形在 y≈420 留下一条硬横线，发梢被齐刷刷截断。要排除衣服，就用领口线渐变；确实需要排除的区域必须有大羽化，或把边放到头发/手的下方。
- 场景框的羽化要留在框内；贴回的内容要与周围景深一致，必要时对场景源做轻微模糊。

## B. 商品 / 海报 / 文字类槽位（product / poster / text）

### 1. 主题不漂移，但必须是真洗
- 与金标保持**同一主题、同一构图家族**，**不得漂移到别的主题或品类**。反例：
  - #662：护肤品 → 厨房
  - #683：唇彩 → 手机；夹克 → 跑鞋
- **轻度重编码不算洗图**。基线是 #667：要能与金标区分开，但构图一致；不得原样复制金标。

### 2. 文字（最终严格规则）
- 金标上**原样出现过的营销文案和数字，全部要改**：促销贴纸、标语、标题、人名、品牌、正文。
- **意译或换同义词不算改**。
- 只有**纯功能性 UI 文字**可以保留，例如按钮、导航、Subscribe、Play。

### 3. 槽位内一致
- 同一槽位内，人物、产品、品牌保持一致。

## C. 通用规则
- **kie 只用于洗示例图**。真实的 skill 生成走 **WaveSpeed**，两边预算分开记账。
- kie：每张最多 2 次；余额低于 300 停止；不充值、不换账号。
- **凡是被 Angela 拒过的图**，合并前必须把新的 L/R 给她看过。

---

## D. 技术门禁
- L/R 对比图**嵌在 PR body 里**，链接固定在 **tip 完整 SHA**（40 位），逐个确认 **HTTP 200**。
- 除 L/R 外，PR body 还必须嵌入每张图**重绘区域的 2 倍放大裁切图**（同样固定在 tip 完整 SHA、HTTP 200）。
- PR body 里写出每个示例的 **sha256** 和**重绘面积 %**（遮罩 > 0.02 的像素占全画面比例）。自检表**以 tip 上的实际文件为准**。
- **meanAbs 只做记录**，不作为门槛；meanAbs≥40 也**不卡合入**。
- `src/skills.ts` 的 `ex643(...)` pin 用资源提交的**完整 SHA**；manifest 写清方法、遮罩参数、prompt，不留旧描述。
- CI 门禁：tsc OK · unit（`skill and not e2e`）0 failed · build OK（dist 不提交）· e2e（`(skill and e2e) or 650 or creator`）全过。
- **顺序**：设计 PASS → 测试 PASS → 技术 GO → 用 `--match-head-commit` 合并。
- **同一时间只能有一个 PR 处于 Ready**，其余保持 draft。

### PR body 检查清单
- [ ] L/R 嵌入、固定在 tip 完整 SHA、HTTP 200
- [ ] 重绘区域 2 倍放大裁切图已嵌入（tip 完整 SHA、HTTP 200）
- [ ] 重绘后 2 倍放大检查：无接缝/晕边、无金标文字残留
- [ ] 未做全图重生成、重滤镜、磨皮
- [ ] 脸部亮度差在 ±3 以内（硬性）
- [ ] 每张：sha256、重绘面积 %、自检（人物类：换人标准、角度、衣服 100% 金标、场景框、脸部亮度差、暗部颗粒；商品类：主题未漂移、文字已全部改写）
- [ ] meanAbs（仅记录，≥40 不卡合入）
- [ ] 门禁结果、kie 调用次数与余额
- [ ] 被拒过的图已给 Angela 看过 L/R
