Every canvas action runs one of the API workflows in `workflows/` (or a small graph built in code) through ComfyUI's `/prompt`. You only need the models for the features you use. The model picker in the generator shows which image and video models are installed.

Folders below are relative to `ComfyUI/models/`.

## Image generation and editing

The default image model. It powers generation, quick edit, edit text, expand, inpaint, style transfer, comment edits and creative upscale.

| File | Folder |
|---|---|
| `qwen_image_2.1_int8_convrot.safetensors` | `diffusion_models` |
| `qwen3vl_8b_int8_convrot.safetensors` | `text_encoders` |
| `qwen_image_2.1_vae_bf16.safetensors` | `vae` |

## Video

Animate image, video generation and video extend use MiniMax H3:

| File | Folder |
|---|---|
| `minimax_h3_fl2va_pruned_int8_convrot.safetensors` | `diffusion_models` |
| `minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors` | `loras` |
| `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | `text_encoders` |
| `minimax_h3_video_vae_fp16.safetensors`, `minimax_h3_audio_vae_fp32.safetensors` | `vae` |

**Reference to video** uses `minimax_h3_ref2va_pruned_int8_convrot.safetensors` (`diffusion_models`) with the same text encoder and VAEs. **Motion control** adds `minimax_h3_fun_controlnet_union_pruned_int8_convrot.safetensors` (`model_patches`), `sdpose_wholebody_fp16.safetensors` (`checkpoints`) and `rt_detr_v4-x-hgnet_fp16.safetensors` (`diffusion_models`) for pose extraction. **Lip sync** uses the image-to-video files above.

Video trim and the video editor use core nodes only.

## Speech and text recognition

`gemma4_e4b_it_fp8_scaled.safetensors` in `text_encoders` powers voice input and, by default, text recognition for Edit Text and Extract Text. Edit Elements always uses RapidOCR, which also returns where each line sits. Text recognition can use the Agent instead; see [Agent settings](/guides/agent#settings).

## Reference modes

Line art, depth, pose and the other structure modes use the [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) preprocessors. MLSD, HED, normal and segmentation download their annotator weights on first use. With Qwen Image 2512, structure modes also use `Qwen-Image-2512-Fun-Controlnet-Union-2602.safetensors` in `controlnet`.
