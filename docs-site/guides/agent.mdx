<Note>**Turn it on in Settings first.** The Agent is off by default. Click **Open Agent Settings** in the Agent panel, then turn on **Enable MCP** and then **Enable Agent** (it needs MCP). See [Settings](#settings) below.</Note>

The Agent panel on the left runs a tool-using agent on the ComfyUI backend. It can look at the canvas, plan a design, generate and edit images, videos, audio and 3D models, rebuild images with Edit Elements, make mockups, place text, shapes, artboards, web pages and slides, ask you clarifying questions, and remember your preferences.

## Modes

The mode switch under the chat box picks what a message does:

- **Agent**: the agent plans and works on the canvas with tools. Needs an agent to be enabled (below).
- **Image** and **Video**: send the prompt straight to a generator, no agent involved. These work out of the box.

An empty chat offers three quick starts: **Upload a reference**, **Start from a skill** and **Use a brand kit**. Select images, videos or audio on the canvas, drag them in, or paste them to attach them as references. Type `/` to pick a skill and `@` to reference brand kits, characters, products or canvas items. Comments can be sent to the chat too, together with the area you marked.

**Upload file** (the + menu), drag and drop, and paste accept:

- **Images and videos**: placed on the canvas and attached. A video is shown to the agent as four frames spread across it; the agent can call `view_video` to look at more frames or one stretch closely.
- **Audio**: placed on the canvas as an audio element. Speech in it is transcribed with WaveSpeed's speech-to-text model before sending, and the agent can use the clip as a voice, lip-sync or reference audio.
- **Documents** (PDF, DOCX, Markdown, TXT): shown as file chips; their text goes to the agent, and for a PDF the first pages are attached as images too. PDFs imported onto the canvas keep each page's text, so the agent can read it with `get_canvas`.

While it works, the Agent can post a plan as a checklist and ticks items off. Its tool calls fold into one line ("Ran 17 steps") that you can expand. When the agent returns readable reasoning (`reasoning_content` or `<think>` text), it appears as a folded **Thought** line. Claude Code only returns encrypted thinking, so nothing is shown for it.

## Settings

The Agent is off by default. Open **Agent Settings** from the mode menu under the chat box and turn on **Enable MCP** and **Enable Agent**.

  <img src="/images/ours/en/agent-settings.webp" alt="Agent settings" />
</Frame>

Loomi uses command-line agents that are already signed in on your machine. It never stores credentials.

Step-by-step setup for each tool, with the status meanings and an FAQ: [External agents](/guides/external-agents).

| Agent | What it needs |
|---|---|
| Claude Code | `claude` on PATH, logged in |
| Codex | `codex` on PATH, logged in |
| Qwen Code | `qwen` on PATH with a model configured in `~/.qwen/settings.json` |
| DeepSeek Harness | `dsh` on PATH, signed in through the DeepSeek Harness app |
| Hermes | [Hermes Agent](https://github.com/NousResearch/hermes-agent) with a model configured, on this machine or another one over SSH (see below) |
| OpenAI-compatible LLM | any OpenAI-compatible endpoint with tool calling; set its URL and model in Agent Settings. If it needs a key, set `COMFYART_LOCAL_LLM_API_KEY` before starting ComfyUI. |


### Hermes

Each turn starts `hermes acp`. The model, skills and memory come from Hermes's own configuration.

- **Hermes SSH host** (Agent Settings): blank runs `hermes` from this machine's PATH. Set a host alias or `user@host` to run it on that machine over `ssh` (key login only). ComfyArt opens a reverse tunnel so Hermes reaches this canvas; ComfyUI does not need to listen on the LAN.
- **Hermes profile**: ComfyArt runs `hermes -p <profile> acp`, `comfyart` by default. Hermes's terminal and file tools cannot be turned off in ACP mode, so give ComfyArt its own profile with no sudo password and a network-less docker terminal:

  ```
  hermes profile create comfyart --no-skills --no-alias
  hermes -p comfyart config set terminal.backend docker
  ```

  Then add `docker_network: false` under `terminal:` in `~/.hermes/profiles/comfyart/config.yaml`.
- Actions that ask for approval are always rejected. Each chat maps to one Hermes session; chats cannot be branched. Attachments are images only.

Other settings:

- **Text recognition**: Edit Text and Extract Text read text with WaveSpeed's `paddle-ocr` model by default. Switch to **Agent** to use the default agent instead.
- **Model Preferences** (button under the chat box): let the agent choose models automatically or fix one per task, with separate Image and Video tabs.

Short single-shot tasks (storyboard split, OCR with the Agent engine, brand and memory extraction, reference notes and the Ideogram caption) go to the default agent without tools.

## Chats

- Chats are saved in a SQLite database (`user/__comfyart/data.db`) and keep running when the panel is closed. The canvas tools run in the open Loomi tab of the project, so keep that tab open while the agent works.
- Stop a run, edit and resend a message, branch a chat, see context usage, and open each result's details (process, outputs, original prompt).
- The agent can review the canvas frame by frame, summarize comments into a fix plan, and point you to results on the canvas.
- The notification center collects suggestions, comment fixes and finished tasks, and a browser notification fires when a task is done.
- **Voice input** transcribes with WaveSpeed's speech-to-text model.

## Chat frames

Each chat gets its own frame on the canvas, named after the chat. Whatever the Agent makes in that chat (images, videos, audio, web pages) lands in the frame, in order, unless it was asked to put it somewhere else. Edits of an existing image still appear next to that image.

- Select a chat frame and click **Open chat** in its toolbar to switch the Agent panel to that chat.
- The frame button in the Agent panel header shows the current chat's frame on the canvas.

## Reference frame

A reference frame is a frame the Agent reads with every message. Click **Ref** on the right of the bar under the chat box: the first click creates a **References** frame on the canvas and links it. Drop images, videos, audio or text notes into it; the button shows how many items it holds. Linked items are attached to every message and the notes are passed along as the brief. Click **Ref** again, or **Linked to chat** in the frame's toolbar, to unlink it.

## Skills

Skills are folders with a `SKILL.md` plus any extra files (images, text). Use the built-in ones, write your own, import a folder, or save a workflow from a chat as a skill. Skills keep version history with rollback. Image files are shown to the agent; text files are included by relevance within a context budget.

## Memory

The agent remembers things across projects: about you, your taste, your way of working and your assets. It can ask onboarding questions, extract memories from uploaded files, and you can change or forget memories just by asking. An evolution log shows what changed.

The **What I can do on my own** tab in Memory holds the switches:

- **Use memory**: when off, the agent neither reads nor saves memories.
- **Auto-update memory**: after each finished chat turn, the default agent picks out lasting preferences you mentioned and saves them.
- **Canvas check-up**: when you open a project that changed since the last check, the canvas is reviewed about a minute later and the problems found are posted to the notification center.
- **Self-evolving skills**: after every few requests, your latest ones are checked for a workflow you repeat; if there is one it becomes a skill, tagged **Learned** in My Skills with the requests it was learned from.
- **Daily runs**: how many times a day each of these may run.

These need the Agent turned on and are off by default.

## Scheduled tasks

Run an agent prompt on a schedule (daily or weekly) while Loomi is open.
