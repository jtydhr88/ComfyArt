生成有三种方式：

- **在画布上**：点底部栏的 **图像生成**（旁边的箭头可以切换到视频或[音频](/zh/guides/audio-3d)）。画布上会出现一个生成卡片，下面带提示词框，卡片的大小就是要生成的图片尺寸。
- **在对话里**：把对话框下面的模式切到 **图像** 或 **视频**，输入提示词发送即可，不经过 Agent。
- **对选中内容**：在画布上选中图片，按 **Shift+Enter**（或点选区工具栏的 **对话**）。见[画布对话](#画布对话)。

结果会放在卡片旁边；ComfyUI 生成时，卡片外圈会显示进度环。登记了[局域网实例](/zh/guides/lan-instances)后，模型旁边的 **运行在** 可以选这张卡片在哪台机器上跑。

## 图像设置

点设置按钮（例如 `1K · 1:1 · 1 张`）打开 **图像设置**：

<Frame>
  <img src="/images/image-settings.webp" alt="图像设置" style={{ maxWidth: '520px' }} />
</Frame>

| 选项 | 可选值 |
|---|---|
| 分辨率 | 1K、2K 或自定义宽高 |
| 宽高比 | 1:1、3:2、2:3、4:3、3:4、16:9、9:16、4:5、5:4、21:9 |
| 数量 | 每次 1 到 4 张 |
| 质量 | 极速、标准、高品质 |
| 风格 | 无、摄影、电影感、插画、3D、动漫、极简、复古 |
| 透明背景 | 开或关 |

图里要出现的文字用引号括起来。Qwen Image 2.1 的中英文文字都画得很准。

## 高级

设置按钮旁边的 **高级** 里有：

- **种子**：默认随机。取消勾选 **随机** 就能输入种子或重新摇一个；种子、提示词和设置都相同时，生成的图也相同。每张结果的 **信息** 里都记着它用的种子。
- **负面提示词**（只有 Qwen Image 2512）：不希望画面出现的东西。其他模型是蒸馏模型，不读负面提示词，所以不显示这一栏。
- **LoRA**：从 `models/loras` 里选任意多个，每个可调 0–200% 的强度。**适用当前模型** 列出元数据和当前模型对得上的 LoRA；**全部** 里能看到其余的，标着「其他模型」或「未知模型」。点星标可以收进 **收藏**。Ideogram 不支持 LoRA。

| Ideogram 4 | 版式、Logo 和文字海报 | 不支持 |

## 参考图

点 **参考图** 添加参考图：Qwen Image 2.1 最多 16 张，Flux.2 Klein、FLUX.3 Klein 和 Qwen Image 2512 的结构类模式不限张数。菜单里有：

- **上传图片**：从电脑上传。
- **从素材选择**：ComfyUI 里已有的文件（上传过的和生成的结果）。
- **从我的素材选择**：[素材库](/zh/guides/assets)条目里保存的图片和 Logo。
- **从画布选择**：提示词框会收起，顶部出现提示条，在画布上点一张图就行。点画布空白处、按 Esc 或点 **取消** 退出。

每张参考图有一个模式：

- **内容、风格、构图**：结果要跟着参考图的哪一方面走。
- **结构类模式**：线稿、MLSD、涂鸦、软边缘、深度、法线、姿态、分割、Tile、重新上色等。ComfyArt 会先跑对应的预处理器；在 Qwen Image 2512 上会走真正的 ControlNet，可以调：
  - **参考程度**。
  - **开始** 和 **结束**：ControlNet 作用在采样的哪一段，比如 0–60% 只定构图，细节交给模型自由发挥。
  - **精度**：预处理器分辨率（512、1024 或 2048），只有带分辨率的模式才有。
  - **适配**：控制图按输出比例裁切，或者直接拉伸。
  - **预览控制图**：只跑预处理器并显示结果，生成前先确认线稿或姿态对不对。改了设置后预览会变暗，点 **重新提取** 即可。

参考图按实际使用的顺序编号（「图 1」「图 2」）。如果当前模型不支持参考图或不支持这个模式，那张参考图会变灰并说明原因，生成照常进行，只是不用它。

## 画布对话

选中一个或多个图片、视频或音频，按 **Shift+Enter**，或点图片工具栏、多选工具栏里的 **对话**。选区下方会弹出输入框，选中的内容已经以 `[图1]`、`[图2]`…… 的形式放在里面。

- 接着打字，打字时再去点画布上的其他内容，每点一个就插到光标处，所以“把 [图1] 放到 [图2] 上”可以一口气写完。删掉某个缩略图，后面的编号会自动顺延。
- **立即生成**（或回车）直接出图，按标签顺序把这些内容作为参考图。**发给 Agent** 把同样的需求和内容交给 [Agent](/zh/guides/agent)。
- 按 Esc 或点 × 关闭。

### 逐张生成

选了两个以上的内容时，可以打开 **逐张生成**：需求会对每个内容各跑一次，而不是所有内容一起跑一次。每个缩略图下面会显示 **逐张** 或 **共用**，标为共用的内容每次都会带上。比如“把这个咖啡杯分别放到这几张桌子上”：把咖啡杯标为共用，就会每张桌子各出一张图，结果放在对应桌子下方。Agent 面板下的对话框里也有同样的开关；交给 Agent 时，会告诉它每个内容各出一个结果。

## 颜色参考

**颜色参考** 用来加一组配色。颜色名会写进提示词；在支持参考图的模型上，还会附一张色块拼图作为参考，让结果用上这套配色，又不会照搬它的布局。鼠标移到某个颜色上点 × 就能删掉。

## 底图

**底图** 把生成变成图生图：从画布上选一张图，再设置结果可以改动多少（0–100）。

## 视频生成

把生成器或对话模式切到 **视频**。视频设置里有：

<Frame>
  <img src="/images/composer-video.webp" alt="从对话框打开的视频设置" style={{ maxWidth: '450px' }} />
</Frame>

- **宽高比** 16:9、9:16、1:1、4:3、3:4 或 21:9；**分辨率** 768p 或 1080p；**时长** 5、10 或 15 秒。
- **运镜**：自动、固定镜头、推进、拉远、环绕、跟随、手持、左摇 / 右摇、上摇 / 下摇。

视频生成器有五种模式：**首尾帧**、**参考生视频**（参考图、视频和音频）、**动作控制**、**对口型** 和 **分镜**。更多见[视频](/zh/guides/video)。
