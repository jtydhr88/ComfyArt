每个画布操作都会通过 ComfyUI 的 `/prompt` 跑 `workflows/` 里的一份 API 工作流（或代码里拼的一小段图）。只需要装你用得到的功能对应的模型。生成器里的模型选择会显示哪些图像和视频模型已经装好。

下面的目录都相对于 `ComfyUI/models/`。

## 图像生成与编辑

默认图像模型。生成、快捷编辑、编辑文字、扩展、局部重绘、风格迁移、评论修改和增强细节放大都靠它。

| 文件 | 目录 |
|---|---|
| `qwen_image_2.1_int8_convrot.safetensors` | `diffusion_models` |
| `qwen3vl_8b_int8_convrot.safetensors` | `text_encoders` |
| `qwen_image_2.1_vae_bf16.safetensors` | `vae` |

## 视频

动态图片、视频生成和视频延长都用 MiniMax H3：

| 文件 | 目录 |
|---|---|
| `minimax_h3_fl2va_pruned_int8_convrot.safetensors` | `diffusion_models` |
| `minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors` | `loras` |
| `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | `text_encoders` |
| `minimax_h3_video_vae_fp16.safetensors`、`minimax_h3_audio_vae_fp32.safetensors` | `vae` |

**参考生视频** 用 `minimax_h3_ref2va_pruned_int8_convrot.safetensors`（`diffusion_models`），文本编码器和 VAE 与上面相同。**动作控制** 另外需要 `minimax_h3_fun_controlnet_union_pruned_int8_convrot.safetensors`（`model_patches`），以及用来提取姿态的 `sdpose_wholebody_fp16.safetensors`（`checkpoints`）和 `rt_detr_v4-x-hgnet_fp16.safetensors`（`diffusion_models`）。**对口型** 用上面图生视频的那套文件。

视频裁剪和视频编辑器只用核心节点。

## 语音与文字识别

`text_encoders` 里的 `gemma4_e4b_it_fp8_scaled.safetensors` 负责语音输入，也默认负责编辑文字和提取文字的文字识别。编辑元素始终用 RapidOCR，它还会给出每一行文字所在的位置。文字识别也可以改用 Agent，见 [Agent](/zh/guides/agent) 页的设置部分。

## 参考模式

线稿、深度、姿态等结构类参考模式用 [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) 的预处理器。MLSD、HED、法线和分割会在第一次使用时下载各自的权重。用 Qwen Image 2512 时，结构模式还会用到 `controlnet` 里的 `Qwen-Image-2512-Fun-Controlnet-Union-2602.safetensors`。
