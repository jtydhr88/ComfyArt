左侧的 Agent 面板会在 ComfyUI 后端运行一个会用工具的 Agent。它能查看画布、规划设计，生成和编辑图片、视频、音频和 3D 模型，用编辑元素重建图片，制作样机，摆放文字、形状、画板、网页和幻灯片，向你提问确认，还会记住你的偏好。

上面的例子里，需求只有一句话，外加画布上选中的那张拿铁照片。Agent 从 Spring menu 画板里读出配色和字体，用可编辑的文字和形状搭了一个新的 1080×1080 画板，并说明了哪些地方能还原、哪些不能。

## 模式

对话框下面的模式开关决定一条消息怎么处理：

- **Agent**：Agent 规划并用工具在画布上干活。需要先启用某个 Agent（见下文）。
- **图像** 和 **视频**：直接把提示词交给生成器，不经过 Agent，装好就能用。

空白对话里有三个快捷入口：**上传本地参考**、**选择 Skill 开始创作** 和 **使用品牌套件**。在画布上选中图片、视频或音频，拖进来或粘贴，都可以把它们作为参考附上。输入 `/` 选择技能，输入 `@` 引用品牌套件、角色、产品或画布上的内容。评论也可以连同你圈出的区域一起发送到对话里。

**上传文件**（+ 菜单）、拖放和粘贴支持：

- **图片和视频**：放到画布上并附上。视频会以均匀分布的 4 帧给 Agent 看；Agent 还可以调用 `view_video` 看更多帧，或细看某一段。
- **音频**：作为音频元素放到画布上。发送前用本地语音模型把里面的人声转成文字，Agent 也可以把这段音频当声音、对口型或参考音频使用。
- **文档**（PDF、DOCX、Markdown、TXT）：以文件标签显示，文字内容交给 Agent；PDF 的前几页还会以图片附上。导入到画布上的 PDF 会保留每页文字，Agent 用 `get_canvas` 就能读到。

工作过程中，Agent 会把计划列成清单，并逐项打勾。它的工具调用会折叠成一行（「执行了 17 个步骤」），展开可以看到每一步和耗时。Agent 返回可读的推理内容时（比如本地模型返回的 `reasoning_content` 或 `<think>` 文字），会显示一行折叠的 **思考过程**，点开可以看。Claude Code 只返回加密的思考内容，所以不会显示。

## 设置

Agent 默认是关闭的。从 Agent 选择菜单里打开 **Agent 设置**，勾选 **启用 MCP** 和 **启用 Agent**。

  <img src="/images/agent-settings.webp" alt="Agent 设置" style={{ maxWidth: '420px' }} />
</Frame>

ComfyArt 使用本机上已经登录好的命令行 Agent，从不保存任何凭据。

| Agent | 需要什么 |
|---|---|
| Claude Code | PATH 里有 `claude`，并已登录 |
| Codex | PATH 里有 `codex`，并已登录 |
| Qwen Code | PATH 里有 `qwen`，并在 `~/.qwen/settings.json` 里配好模型 |
| DeepSeek Harness | PATH 里有 `dsh`，并已通过 DeepSeek Harness 应用登录 |
| Hermes | 本机或可 SSH 登录的另一台机器上装好 [Hermes Agent](https://github.com/NousResearch/hermes-agent) 并配好模型（见下文） |
| 本地大模型 | 任何支持工具调用的 OpenAI 兼容接口，在 Agent 设置里填地址。需要密钥的话，启动 ComfyUI 前设置环境变量 `COMFYART_LOCAL_LLM_API_KEY`。 |

### Hermes

每轮对话启动一次 `hermes acp`。模型、技能和记忆都用 Hermes 自己的配置。

- **Hermes SSH 主机**（Agent 设置）：留空就运行本机 PATH 里的 `hermes`。填主机别名或 `user@host` 就通过 `ssh` 在那台机器上运行（只支持密钥登录）。ComfyArt 会开一条反向隧道让 Hermes 连回这个画布，ComfyUI 不用监听局域网。
- **Hermes profile**：ComfyArt 运行 `hermes -p <profile> acp`，默认 `comfyart`。ACP 模式下关不掉 Hermes 的终端和文件工具，所以给 ComfyArt 单独建一个 profile，不配 sudo 密码，终端用不联网的 docker：

  ```
  hermes profile create comfyart --no-skills --no-alias
  hermes -p comfyart config set terminal.backend docker
  ```

  再在 `~/.hermes/profiles/comfyart/config.yaml` 的 `terminal:` 下加 `docker_network: false`。
- 需要审批的操作一律拒绝。每个对话对应一个 Hermes 会话，不能分支。附件只支持图片。

其他设置：

- **comfy-mcp**：可以同时挂载官方的 comfy-mcp，让 Agent 能查节点、模型和模板。
- **文字识别**：编辑文字和提取文字默认用 ComfyUI 里的本地 Gemma 4 模型识别，加载和识别时会显示进度。也可以切换成 **默认 Agent**，交给默认 Agent 识别。
- **模型偏好**（对话框下面的按钮）：让 Agent 自动选模型，或给每类任务固定一个模型，图像和视频分开设置。

一些单次的小任务（分镜拆分、用 Agent 识别文字、提取品牌和记忆、参考图分析、Ideogram 描述）会直接交给默认 Agent，不带工具。

## 对话

- 对话保存在 SQLite 数据库（`user/__comfyart/data.db`）里，关掉面板也会继续运行。画布工具由该项目打开着的 ComfyArt 标签页执行，所以 Agent 工作时请保持这个标签页开着。
- 可以中途停止、编辑后重发消息、从某条消息分支出新对话、查看上下文用量，并打开每个结果的详情（过程、产出、原始提示词）。
- Agent 可以逐个画板检查画布、把评论汇总成修改计划，并帮你在画布上定位结果。
- 通知中心汇总建议、评论修改和已完成的任务；任务完成时还会弹浏览器通知。
- **语音输入** 用本地语音识别模型转文字。

## 对话画框

每个对话在画布上都有一个自己的画框，以对话标题命名。Agent 在这个对话里做出的东西（图片、视频、音频、网页）会按顺序放进这个画框，除非你让它放到别处。修改已有图片的结果仍然放在那张图旁边。

- 选中对话画框，点工具栏里的 **定位对话**，Agent 面板就会切换到这个对话。
- Agent 面板标题栏里的画框按钮，可以在画布上定位当前对话的画框。

## 参考区

参考区是一个 Agent 每条消息都会读取的画框。点对话框下方 Agent 选择器旁的 **参考**：第一次点会在画布上新建一个 **参考区** 画框并链接。把图片、视频、音频或文字说明拖进去，按钮上会显示里面有几项。链接后，里面的内容会随每条消息一起附上，文字说明会作为需求说明传给 Agent。再点一次 **参考**，或点参考区工具栏里的 **已链接对话**，即可断开。

## 技能

技能是一个文件夹，里面有一个 `SKILL.md` 和任意附加文件（图片、文本）。可以用内置技能、自己写、导入文件夹，或者把对话里的做法保存成技能。技能有版本历史，可以回滚。图片文件会给 Agent 看；文本文件会按相关性在上下文预算内收进去。

## 记忆

Agent 会跨项目记住你的信息：关于你、你的审美、你的工作方式和你的素材。它可以问你一些引导问题、从上传的文件里提取记忆；想改或想让它忘掉什么，直接在对话里说就行。演变日志会记录每次变化。

记忆里的 **自主能力** 页签有这些开关：

- **使用记忆**：关闭后 Agent 不再读取也不再保存记忆。
- **自动更新记忆**：每轮对话结束后，由默认 Agent 挑出你提到的长期偏好并记下来。
- **画布体检**：打开一个自上次检查后有改动的项目，约一分钟后检查画布，把发现的问题发到通知中心。
- **自进化 Skill**：每隔几条请求，检查你最近的请求里有没有反复出现的流程；有的话就总结成 Skill，在「我的技能」里标为 **自动总结**，并注明是从哪些请求学到的。
- **每日次数**：每项能力每天最多运行几次。

这些能力需要先开启 Agent，默认都是关闭的。

## 定时任务

ComfyArt 开着时，可以让某条 Agent 指令按计划（每天或每周）自动运行。
